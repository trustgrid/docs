{{% pageinfo %}}
This page shows events from all nodes in an organization. Events are emitted from nodes and from the Trustgrid control plane when actionable things happen. Events are the basis for alarms and notifications.
{{% /pageinfo %}}

Organization events are available by navigating to **Operations** > **Events**. This is the same data visible on a node's [Events]({{<relref "docs/alarms/events" >}}) page, with the addition of a **Node** column and the ability to filter by specific node names in **Advanced Search**.

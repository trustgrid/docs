---
title: "Cluster Changes"
linkTitle: "Changes"
description: "Changes panel for Trustgrid Clusters"
---

The **Changes** panel displays a history of configuration changes made to the cluster, including changes to network settings, system configurations, and more. This is the same data visible in the [Operations > Changes]({{<relref "/docs/operations/changes">}}) but scoped to those changes applied to the current cluster.
